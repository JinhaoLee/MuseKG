**Important:**

Question: "Who produced 'Demonstration Brass Telescope'?"
Answer:
```python
for node, data in g.nodes(data=True):
    if data.get("type") == "object" and data.get("title") == "Demonstration Brass Telescope":
        for neighbor in g.neighbors(node):
            edge_data = g.get_edge_data(node, neighbor) or {}
            if any(edge.get("relationship") == "has_primary_producer" for edge in edge_data.values()):
                print(g.nodes[neighbor].get("title"))
```
