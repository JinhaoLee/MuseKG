# Data and privacy boundary

The collection used in the MuseKG paper is not distributed in this repository. Raw
records, images, OCR, extracted entities, generated graphs, QA pairs, model responses,
and detailed evaluation logs derived from that collection remain private.

The checked-in example is fictional and exists only to exercise the public pipeline.
Paper results cannot be reproduced exactly without access to the original collection.
Researchers seeking access should contact the authors; access may depend on collection
owner approval and an appropriate data-use agreement.

A public deployment must use fictional, open, or explicitly licensed records. Hosting
the demo against a private graph can expose its contents through answers and graph
neighbourhoods even when the graph file itself is not downloadable.
